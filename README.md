# Street Racer

A 2D pseudo-3D arcade street-racing game for **My PC** (Samsung TV app, Tizen 8+) and desktop Chrome.
Everything (cars, tracks, art, sounds) is original and generated by code. Car makers are fictional.

- **Campaign**: 8 tracks x 3 events (Street Race, Time Attack, Takedown Hunt), stars unlock events and cars.
- **Quick Race**: any unlocked track, 1-5 laps, 5 rivals, pick any car you own.
- **Multiplayer**: 2 players, split screen (top / bottom), same track, traffic, ramming.
- **Garage**: 12 cars from 4 fictional brands (Kairo, Voltrix, Nordhaven, Solara), 4 upgradable stats each.
- 8 themes: night city, desert highway, snowy pass, coastal sunset, forest, volcanic canyon, harbor, cherry hills.
- Progress (coins, cars, upgrades, stars, best times, settings) is saved with `MyPC.save`; career score goes to `MyPC.submitScore`.
- Texts: English, French, Spanish, Arabic (`info.lang`).

## Controls (arrows + OK only)

| Action | Remote / keyboard |
|---|---|
| Steer | Left / Right |
| Brake, or drift in a corner (Down + steer) | Down |
| Nitro | OK (Enter) or Up. Double-tap OK = perfect nitro |
| Pause | Back / Esc (My PC pause menu: Resume, Restart race, Garage, Quit) |

Multiplayer: each player keeps one controller. Player 1 is the controller that opened Multiplayer
(TV remote, W A S D keys or a gamepad); player 2 joins by pressing OK on any other controller and can pick
their car with left / right. In the race each car only reads its own controller. Player 2 needs a second
device that My PC reports separately, so 2-player mode works inside My PC; opened directly in a browser,
the SDK only reports the arrow keys.

## Files

`index.html`, `mypc-app.json`, `icon.svg`, `.nojekyll`, `js/` (`i18n.js`, `track.js`, `art.js`, `audio.js`, `game.js`). No build step.

## Publish and install

1. Push to GitHub, then Settings > Pages > Deploy from a branch > `main` / root.
2. Check `https://<user>.github.io/<repo>/mypc-app.json` opens.
3. Open https://imad-os.github.io/g/installer/ , paste `https://<user>.github.io/<repo>/`, press Check, then Install.
